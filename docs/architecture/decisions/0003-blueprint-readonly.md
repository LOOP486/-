# ADR-0003：蓝图只读，新逻辑一律 C++

- 状态：已接受
- 日期：2026-06-10

## 背景

蓝图节点级编辑是编辑器桥实现成本最高、出错率最高的部分；而用户的工作流本就以 C++ 实现功能为主，蓝图只需要"能读懂"。

## 决策

编辑器桥的蓝图工具只做只读：`bp_overview` / `bp_pseudocode` / `bp_graph` / `bp_find_usages`。新逻辑由 agent 写成 C++（`UFUNCTION(BlueprintCallable)` 等暴露给蓝图层），蓝图侧接线由人完成。

## 备选与取舍

- 完整蓝图编辑（参考 flopperam 的 40+ 节点类型 API）：能做，但验证困难（接错线难以发现）、维护面大，与用户工作流不符，否。

## 后果

- 编辑器桥自研成本降低一半以上；蓝图只读导出恰是现有开源的弱项，是我们的差异化重点。
- 个别"只差一根线"的场景需要人工收尾，可接受。
